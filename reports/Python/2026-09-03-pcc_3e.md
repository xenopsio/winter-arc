## What I Learned

### `.reverse()`

`.reverse()` reverses the current order of the items in a list.

It does not sort the list. It simply puts the last item first, the second-to-last item second, and so on.

**Script:**

```python
Projects = ['phishcore-x', 'ESE', 'C5']

Projects.reverse()

print(Projects)
```

**Result:**

```text
['C5', 'ESE', 'phishcore-x']
```

---

### Reassigning List Items

A specific item in a list can be changed by using its index and assigning it a new value.

For example:

```python
Projects = ['phishcore-x', 'ESE', 'C5']

print(Projects)

Projects[0] = "XenOPS"

print(Projects)
```

Here, `Projects[0]` points to the first item in the list. By assigning `"XenOPS"` to it, the original value `"phishcore-x"` is replaced.

**Result:**

```text
['phishcore-x', 'ESE', 'C5']
['XenOPS', 'ESE', 'C5']
```
