.lower() and .upper()

The string method .upper changes all text into Upper letter whereas .lower() does the exact opposite by changing everything to lower letter.

Here is an example:

PX = "We'll rise alongside Phishcore-X and i am Xen the one whose gonna go ghost mode."
print(PX.upper())
print(PX.lower())

Result:

WE'LL RISE ALONGSIDE PHISHCORE-X AND I AM XEN THE ONE WHOSE GONNA GO GHOST MODE.

So now we will learn Listing in python :

First of all to create a list we need to use square brackets and separate items with commas in apostrophe or quotation marks, example provided below:

PX = ['XenOps', 'XenSec', 'Xen', 'Xe']
print(PX)

Now once we know how to create  a list we need to know how to extract specific data from the list. In order to do so we need to provide the listing number of the item we want ex : if we wanted “Xe” from the list above we would print(PX[3]).  Why print 3 instead of 4? It’s because in python and other programming languages the counting starts from 0 not from 1 so it’s 0 then 1 then 2 then 3 and so onward. Example below:

PX = ['XenOps', 'XenSec', 'Xen', 'Xe']
print(PX[3])


Result:

Xe
