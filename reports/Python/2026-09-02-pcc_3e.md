## Sort:

So by using the sort we can give the text and orders order depending of script if we use only .sort() it will order the words in alphabetical format example below:

Script:

Projects = ['phishcore-x', 'ESE', 'C5']
Projects.sort()
print(Projects)


Result:

['C5', 'ESE', 'phishcore-x']


See the order in which the result came that’s how sort works but we can also reverse it, by reversing i mean in sorts the result in counter alphabetical format.

Script:

Projects = ['phishcore-x', 'ESE', 'C5']
Projects.sort(reverse=True)
print(Projects)




Result:

['phishcore-x', 'ESE', 'C5']

Sorted and \n :
